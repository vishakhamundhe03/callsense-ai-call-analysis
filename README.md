🚀 Excited to share my latest project — **CallSense: AI-Powered Call Analysis & Admin Portal**! 🎙️🤖

I built CallSense to analyze customer calls and transform conversations into meaningful insights.

✨ **What CallSense can do:**

🎙️ Upload and analyze customer calls  
📝 Generate and process call transcripts  
😊 Detect customer sentiment  
📊 Estimate purchase intent  
💡 Generate useful customer insights  
🔍 Search and filter call records  
🔄 Re-analyze calls  
📄 Generate downloadable PDF reports  
🗄️ Store call data using SQLite  

🛠️ **Technologies Used:**

• Python  
• Flask  
• REST APIs  
• SQLite  
• HTML, CSS & JavaScript  
• Transformers & PyTorch  
• Faster-Whisper for audio transcription  
• Git & GitHub  

One important learning from this project was understanding the difference between a **demo AI scoring system** and a properly trained production ML model. The current purchase likelihood score is transparent and heuristic-based, while a real production model would require historical labeled data, validation, calibration and continuous monitoring.

Building this project helped me gain hands-on experience with **AI integration, backend development, REST APIs, databases, audio processing, dashboards and report generation**.
